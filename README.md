## ✨ 2. 주요 기능
- **정밀한 A-B 구간 반복**: 시작점과 종료점을 지정하고 `-0.1초`, `+0.1초` 등 세밀하게 조절하여 원하는 구간만 무한 반복 재생할 수 있습니다.
- **스마트 소셜 공유 (카카오톡 외)**: 유튜브 oEmbed API를 연동하여 영상의 실제 제목과 썸네일을 자동으로 가져오며, 카카오 SDK를 활용해 로그인 없이 간편하게 카카오톡 공유가 가능합니다.
- **커스텀 타이틀 및 설명**: 공유 시 표시되는 제목과 설명(`00:00.0 ~ 00:10.0 무한 구간 반복` 등)을 사용자가 직접 입력할 수 있습니다.
- **URL 파라미터 자동 연동**: 설정한 구간과 타이틀이 포함된 고유 링크(`?v=...&start=...&end=...&title=...`)가 생성되어, 링크를 받은 상대방은 클릭 한 번으로 해당 구간이 자동 세팅됩니다.
- **로컬 저장 및 백업**: 자주 사용하는 반복 구간을 브라우저(`localStorage`)에 저장하고, JSON 파일 형식으로 백업 및 복원(내보내기/가져오기)할 수 있습니다.
- **재생 속도 및 카운터**: 0.5배속부터 2배속까지 자유로운 재생 속도 조절 및 실시간 반복 횟수(Loop Count) 카운팅을 지원합니다.

## 🛠️ 3. 트러블슈팅 & 4. 해결 방법
- **이슈 1: 모달창 UI 및 UX 개선 (외부 클릭 시 닫기)**
  - **원인**: 공유 모달창이 열렸을 때 X 버튼을 눌러야만 닫히도록 설계되어 모바일 및 PC 환경에서 사용자 경험이 떨어짐.
  - **해결**: 모달 배경 영역에 `handleModalOutsideClick` 함수를 적용하여, 모달 콘텐츠 박스 바깥의 어두운 배경을 클릭할 경우 창이 자연스럽게 닫히도록 이벤트 핸들러 구현.
- **이슈 2: 카카오톡 공유 시 '인증 실패 (Error 4019)' 발생**
  - **원인**: 카카오 디벨로퍼스에 등록된 웹 도메인 주소와 실제 배포된 주소가 일치하지 않거나 누락되어 발생.
  - **해결**: 카카오 디벨로퍼스 플랫폼 설정의 Web 도메인에 깃허브 배포 주소(`https://minjukang727.github.io`)를 정확하게 등록하여 해결
- **이슈 3: 카카오 SDK 스크립트 로딩 보안 차단 (`integrity` 에러)**
  - **원인**: 브라우저에서 SDK 파일의 무결성 검증 값 불일치로 스크립트 실행이 차단되는 현상.
  - **해결**: 스크립트 태그 내의 불필요한 `integrity` 및 `crossorigin` 속성을 제거하여 원활하게 로드되도록 수정.
- **이슈 4: 유튜브 영상 임베드 오류 (Error 153 등)**
  - **원인**: 외부 도메인에서 유튜브 아이프레임을 직접 로드할 때 보안 정책이나 레퍼러(Referrer) 설정 문제로 재생이 막히는 현상.
  - **해결**: `youtube-nocookie.com` 호스트 주소를 사용하고 `referrerpolicy="strict-origin-when-cross-origin"` 보안 헤더를 적용하여 안정적인 재생 환경 구축.
- **이슈 5: 유튜브 실제 제목 및 썸네일 동적 연동의 한계 (CORS 이슈)**
  - **원인**: 프론트엔드 단에서 유튜브 API를 직접 호출할 때 보안 정책(CORS)으로 인해 영상 제목을 가져오기 까다로움.
  - **해결**: 별도의 백엔드 서버 없이 프론트엔드에서 안전하게 영상 제목을 가져올 수 있도록 유튜브 공식 `oEmbed API`를 비동기(`fetch`)로 연동하여 해결.

## ❓ 5. FAQ (자주 묻는 질문)
- **Q. 카카오톡 공유할 때 로그인이 필요한가요?**
  - A. 아닙니다! 카카오톡 앱 자체의 공유 인터페이스를 활용하는 방식이므로 별도의 웹사이트 로그인 없이 바로 친구나 채팅방에 공유할 수 있습니다.
- **Q. 모바일 환경에서도 사용할 수 있나요?**
  - A. 네, 반응형 UI로 제작되었기 때문에 스마트폰 브라우저나 태블릿에서도 PC와 동일하게 구간 반복 및 공유 기능을 이용할 수 있습니다.
- **Q. 저장한 구간 데이터가 사라지면 어떡하나요?**
  - A. 브라우저의 `localStorage`에 자동 저장되지만, 상단의 '내보내기' 버튼을 통해 언제든 JSON 백업 파일로 안전하게 보관할 수 있습니다

## 🎯 YouTube Loop Player 활용 백서 (사용 가이드)
### 1. 외국어(어학) 섀도잉 및 리스닝 공부
- **활용법**: 외국어 인강이나 뉴스, 팝송 영상에서 잘 들리지 않는 문장이나 발음 구간을 A-B 구간 반복으로 설정합니다.
- **추천 팁**: 재생 속도를 `0.75x` 또는 `0.5x`로 낮추고 `-0.1초`, `+0.1초` 미세 조절 버튼을 활용해 원어민의 발음과 억양을 완벽하게 따라 하는 섀도잉(Shadowing) 연습에 활용해 보세요.

### 2. 댄스 안무 및 숏폼(릴스/틱톡) 연습
- **활용법**: 아이돌 안무 영상이나 댄스 커버 영상에서 특정 파트(후렴구, 브릿지 등)만 지정하여 무한 반복 재생합니다.
- **추천 팁**: 동작을 느리게 따고 싶을 때는 재생 속도를 `0.75배속`으로 맞추고, 안무가 익숙해지면 원래 속도로 높여가며 연습할 수 있습니다. 반복 횟수 카운터로 몇 번이나 연습했는지 실시간으로 체크할 수 있습니다.

### 3. 악기 연주 (기타, 피아노, 드럼 등) 연습
- **활용법**: 연주하기 까다로운 고난도 솔로 파트나 마디를 구간 반복으로 설정해 손에 익을 때까지 끊김 없이 연습합니다.
- **추천 팁**: 연습하던 구간의 정확한 시작과 끝 타이밍을 '구간 제목 / 메모'와 함께 '현재 구간 저장하기'로 로컬 스토리지에 저장해 두면, 다음에 접속했을 때 클릭 한 번으로 곧바로 이어서 연습할 수 있습니다.

### 4. 스터디 그룹 및 팀원 간 공유 (카카오톡 연동)
- **활용법**: 공부하거나 연습해야 할 핵심 유튜브 구간을 설정한 뒤, '구간 공유하기' 버튼을 눌러 카카오톡이나 SNS로 팀원들에게 공유합니다.
- **추천 팁**: 카카오톡 공유 시 유튜브 영상의 실제 제목과 썸네일, 그리고 `00:00.0` ~ `00:10.0` 무한 구간 반복 같은 상세 설명이 미리보기로 깔끔하게 전송됩니다. 링크를 받은 상대방은 로그인 없이도 터치 한 번으로 정확히 그 구간의 반복 재생기로 바로 진입할 수 있습니다.
