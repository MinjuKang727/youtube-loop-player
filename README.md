
# 🎬 YouTube Loop Player (유튜브 구간 반복 플레이어)

> 공부, 어학 학습, 악기 연습, 댄스 안무 연습 등을 위해 유튜브 영상을 원하는 구간만큼 무한 반복하고 링크로 쉽게 공유할 수 있는 웹 애플리케이션입니다.  
> 별도의 설치나 백엔드 서버 없이 정적 웹페이지(HTML/JS)로 작동하며, **GitHub Pages**를 통해 누구나 무료로 배포하고 사용할 수 있습니다.

---

## ✨ 주요 기능

1. **구간 반복(A - B)**
   - 시작 시간(A)과 종료 시간(B)을 지정하여 원하는 구간만 무한 반복 재생할 수 있습니다.
   - `-1초`, `-0.1초`, `+0.1초`, `+1초` 미세 조절 버튼 제공
2. **URL 파라미터 링크 공유**
   - 설정한 구간과 제목이 포함된 고유 링크를 원클릭으로 복사(`?v=...&start=...&end=...&title=...`)할 수 있습니다.
   - 링크를 공유받은 상대방은 별도 설정 없이 열기만 해도 해당 구간이 자동 세팅됩니다.
3. **즐겨찾기 및 로컬 저장 (localStorage)**
   - 자주 사용하는 구간을 브라우저에 저장하고 언제든 불러올 수 있습니다.
   - JSON 파일 백업 및 복원(내보내기/가져오기) 지원
4. **재생 속도 및 카운터**
   - 0.5배속부터 2배속까지 자유로운 재생 속도 조절
   - 반복 횟수(Loop Count) 실시간 카운팅
5. **오류 방지 (Error 153 대응)**
   - `youtube-nocookie.com` 도메인 및 `referrerpolicy` 적용으로 안정적인 재생 환경 제공
